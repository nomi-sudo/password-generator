# 🔐 Password Generator

A simple Streamlit web app that generates a random password with a custom mix of letters, symbols, and numbers.

## Run it

```bash
pip install -r requirements.txt
streamlit run password_ui.py
```

Then open http://localhost:8501 in your browser.

## How it works

- Choose how many **letters**, **symbols**, and **numbers** you want (0–50 each, defaults 8/2/2)
- Click **Generate** — the characters are picked at random and shuffled
- Copy your password from the code box
